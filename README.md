# The Dad Field Manual

An unofficial companion for guys reading [Fathercraft](https://fathercraft.com/) and
working through Father's Ed. Checklists, a weekly dad-habits scorecard, and field
notes — in one free, fast, offline-capable page.

**Not affiliated with or endorsed by Fathercraft.** All checklist text here is
original. Their course is the real deal; this is just a place to do the work.

## What's inside

- **Before Baby** — 15 items to knock out before the due date
- **Hospital Day** — your job as her calm, her advocate, baby's first responder
- **First Weeks Home** — shifts, food, sleep, zero heroics
- **Home Safety** — walk the house like an inspector
- **Dad Habits** — five habits, seven days, pass/fail. Your score, not your kid's behavior.
- **Field Notes** — space to write what you're learning and what you'll actually do

Progress, notes, and habit data live in your browser's localStorage. No accounts,
no tracking, no server. Works offline once loaded.

## Run it locally

Any static file server, e.g.:

```bash
python -m http.server 8000
# then open http://localhost:8000
```

Or just open `index.html` in a browser.

## Print it

Every section has a print button in the footer — checklists, habits grid, and
notes print clean on paper.

## Deploy

GitHub Pages: push to `main`, enable Pages → Deploy from branch → `/ (root)`.
